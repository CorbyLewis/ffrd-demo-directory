# FFRD standard directory structure

Every FFRD basin project uses the same folder layout. Select a folder below to see
what belongs in it, or filter by a word such as *levee* or *hot-fix*. Each selection
has its own link, so you can send a colleague straight to the folder you mean.

[Download the empty template (.zip)](assets/ffrd-template.zip){ .md-button .md-button--primary }

The download contains every folder shown here. Each folder holds a `README.md` with
the same description you read on this page, so the guidance travels with the project.
